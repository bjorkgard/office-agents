## Working plan (accepted scope)

Enum (v1, label text from a fixed table in `src/office`): `explore` Explore, `plan` Plan, `general` General, `other` Subagent (design D3). Unknown or missing `subagent_type` maps to `other`.

1. `shared/events.ts`: add `SubagentKind` enum; the handoff field is named `subagentKind` (not `kind`, which is the event discriminator; eng finding 1). Add an optional-enum `FieldSpec` type (today only object fields can be optional, `events.ts:142-145`). Field allowed on handoff `out` only; `back` rejects it: `SPEC` is keyed by event kind, so add a direction check after `parseFields` in `parseAgentEvent`. Update the header table (enum only, no free text) and `events.test.ts`.
2. `server/normalize.ts`: read `input.subagent_type` for both `Agent` and `Task` tool_use, map to the enum, store the kind in `state.launches` at tool_use time, and attach it when `out` is emitted at tool_result time. The raw string never leaves the server. A queue-operation `back` with no prior `out` carries no kind.
3. `src/office/machine.ts`: `OfficeState.kinds` maps child agent key to `subagentKind`, capped at 2000 (oldest evicted, like `returned`), written on handoff `out` (eng R1; a child may not exist yet when `out` arrives and nested children's kinds must reach the top parent's sheet). A subagent without a kind shows `other`.
4. `src/office/paper.ts`, `Scene.tsx` (overlay), `scene.css`: spans carry their child key; `fold` collects the distinct kinds of spans live or fading at `now`, in order of span start, max 3 then `+N` (D7, eng finding 2); `stillPaperOnDesk` does the same. A focusable hit target (HIT_MIN, in the unscaled overlay, D9) with a CSS-revealed sibling label on `:hover` and `:focus` (eng R2); no React state; target unmounts with the paper. Token colours only.
5. Fixtures and tests (tooltip closes when the paper fades; focus returns to the parent hit button when the paper vanishes; verify no second `out` on a resumed child; generalise `optional` on `FieldSpec` instead of a new type): add `subagent_type` to the Task/Agent fixtures, events guard (enum accepted, free string and `back` rejected), normalize map (known, unknown, hostile value, `Agent` and `Task`), leak test asserts the raw string never appears, mixed-kind label, hover and focus e2e.
6. `server/normalize.ts`: new `DriftReason` (D11) bumped when `subagent_type` is missing or unmapped; counts only. Before merge: `vp run perf` rerun (D10).
7. DESIGN.md: Components entry, Interaction states, Principle 4 note that closed-enum labels are allowed; README privacy line.

Order: first confirm `subagent_type` on real transcripts (D4), then build. Fallback: if real transcripts show no `subagent_type`, every paper reads `Agent` and the plan is blocked on the real-transcript TODO before merge.

NOT in scope: free-text description (D2), `.meta.json` read (D4), label on the character (D6, deferred).
