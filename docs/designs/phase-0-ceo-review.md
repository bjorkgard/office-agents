## Section findings (strategy depth)

1. **Architecture.** Phase 0 touches only docs and `NOTICE`; it gates S5 (recolor, Scene, Character, iso) and DT3/DT5. Boundary is clean. WARNING: dependency graph is correct but the exit condition ("one pack passes") is binary while 7B allows a mixed outcome (pack plus vector fallback for some poses). Pending, owner: implementer of 0.1; record in the notes which poses use the fallback so Phase 4 does not rediscover it.
2. **Error and rescue.** Failure mechanisms: no pack passes (rescue: 7B vector fallback for missing poses only); license unclear or not truly CC0 (rescue: reject the pack, record why in `NOTICE`); shirt band bleeds (rescue: X2 catches it, then next pack or fallback). Implementation owner must prove each by writing the verdict per pack in the notes.
3. **Security.** Downloading asset packs from the web: only from the pack's own page, record source URL and license text in `NOTICE`, do not execute any bundled scripts. Agents downloading files need your explicit permission per download in this setup. Likelihood Low, impact Low.
4. **Data flow and edge cases.** No runtime data flow. Edge case: a pack with 2 facings only. Handled by X3 (mirroring or reject).
5. **Code quality.** X2 script is throwaway and must live outside `src/` (for example the scratch dir), or be deleted before commit. WARNING if it lands in the repo: it would collide with the later `recolor.ts`.
6. **Tests.** No automated test fits a visual gate. Verification is the notes checklist: per-pack pose table, 9-variant contact sheet, 12-sprite 50% screenshot. The unit palette test (DT3) and E2E pixel probe (T13) stay in later phases.
7. **Performance.** Record native sprite sheet size in KB; recolor cache bound is 8 colors x 2 x sheets (already in the re-review). Check the sheet is small enough that 12 agents do not need per-frame work.
8. **Observability.** Not applicable to a docs gate. The one equivalent: the notes file is the only record, so make it self-contained (pack name, URL, license, date, verdict).
9. **Deployment.** None. Rollback: delete the branch, or revert the notes commit. Time: under a minute.
10. **Long-term.** Reversibility 4/5: swapping the pack later is possible but costs recolor and animation rework, which is why this gate exists. Debt: provenance in `NOTICE` prevents a dead link later.
11. **Design.** UI scope exists in later phases; Phase 0 itself adds none. X1 and X3 serve the open layout decision and the 6D scale rule. Consider /plan-design-review only after a pack is chosen, with real sprites to look at (no mockup was ever seen in the earlier design review).
